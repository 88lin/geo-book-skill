# 全平台 NAP 对照表

> 产出自 [capabilities/lso-local-playbook.md](../../references/capabilities/lso-local-playbook.md) 第 6 步。
> NAP = Name / Address / Phone。**不一致 = 隐形扣分，商户自己毫无察觉。**

## 唯一标准写法（先定这个，再逐平台改齐）

| 字段 | 标准写法 | 注意 |
|---|---|---|
| 名称 | | 含括号全半角、后缀写法（如"某某少儿美术（XX 街区店）"）。品类选准不贪大，宁可窄而准 |
| 地址 | | "室"还是"号"要统一；门牌到号 |
| 电话 | | 固话/手机/400 选一个主号，全网一致 |
| 品类 | | 用户会搜的词，不是内部叫法 |
| 简介 | | 自然带地域锚点（商圈名/街区名/学校名） |
| 营业时间 | | |

## 五步执行进度

| 步 | 动作 | 现状 | 完成标准 | 状态 |
|---|---|---|---|---|
| 1 | 盘点认领：全平台搜自己店名，逐个认领商户页，核对图钉到店门口 | | 无"按导航找不到店"的错位 | |
| 2 | 统一 NAP：建全平台信息表，定唯一标准写法，逐平台改齐 | | 任两平台信息逐字一致 | |
| 3 | 补齐货架：上线低门槛体验品/套餐，配齐环境照、产品照、资质介绍 | | 商户页无空相册、无缺失价格 | |
| 4 | 评价运营：把"邀请评价"嵌进服务交付的满意时刻；差评逐条认真回复并转化为改进 | | 新增评价来自真实服务流程 | |
| 5 | 本地内容：每周 2–3 条带地名的门店内容（抖音定位 + 公众号社区活动） | | 连续 4 周稳定产出 | |

## 三要素诊断（为什么排不过同行）

| 要素 | 现状 | 可改动作 |
|---|---|---|
| 相关性 | 招牌写清卖什么了吗？关键词进商户名后缀与简介了吗？ | |
| 距离 | 店搬不走，但图钉可以校准到门；多门店每家单独做商户页 | |
| 知名度 | 综合信号 ≠ 好评率——两百条真实评价偶带差评且认真回复，排得过十条清一色五星 | |

|---|---|---|---|---|---|

**三条纪律**：引导而非收买（刷评处罚比没评价严重得多）；回复比评分重要（认真具体不辩解的差评回复是做给围观者看的）；差评当产品反馈（三条都提"约课难"就是排课系统问题）。

**红线**：绝不刷评——花钱买的每颗星都是雷。跳步执行（只做第 4 步刷评）会触发处罚。

## 边界

- 本卡是体力活清单，无捷径；门槛不在技巧，在执行的完整度。
- 平台规则（认领流程、评价机制）随平台变化，执行前以各平台现行规则为准。
- "三个月进第一屏"是书中案例数字，**不可承诺**。
