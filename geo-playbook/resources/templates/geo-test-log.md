| # | query | 引擎 | 端 | 第几次 | 是否带出可提取的外部引用来源（二值） | 引用域名清单 | 引用呈现位置 | 是否提到本品牌 | 证据等级 | 答案原文存档 |

**口径**：引用率 = 该题回答是否带出可提取的外部引用来源（**二值**，记"几/12"），**不是引用条数**。

**引用呈现位置差异**（跨引擎对比时要知道提取难度不一）：DeepSeek 内嵌引文 / 元宝"源"面板 / 千问接口回抓 / 文心按"参考资料"站名。

**证据等级**：A = 人工/浏览器真实样本（有答案原文与来源链接）；B = API 可复现样本（注明是否联网）；C = 合成演示或推断；D = 待复核（**个人日常账号采样自动降 D**——它测的是"AI 对你的画像"，不能当可见性证据）。

**「没提到」也要照记**——那正是最重要的数据。

## 四、判读

| query | 引擎 | 引用次数/总次数 | 判定 | 依据 |
|---|---|---|---|---|
| | | __ / __ | 🔴 红灯 / 🟡 黄灯 / 🟢 绿灯 | |

- 🔴 **红灯**（稳定零引用，如 0/5）→ 不投入或换引擎。引擎对价值观/方法论类开放题倾向纯模型作答。
- 🟡 **黄灯**（引用不稳定）→ 加大样本或先小成本试投。
- 🟢 **绿灯** → 核对引用源级别是否够得着（你的内容要能进那个级别），卡位才成立。

**n=1 只能回答"引得多/几乎不引/信源构成"这类方向性问题，禁止精确百分比比较。**

## 五、国产平台采样坑（API 路线必读）

| 平台 | 坑 |
|---|---|
| 千问 | OpenAI 兼容端点即使传搜索参数也不返回 search_info，必须走原生端点 + forced_search 才有带 site_name 的来源 |
| 火山方舟（豆包） | /chat/completions 不支持联网；/responses + web_search 默认 ToolNotOpen，内容插件需控制台单独开通——**开通前后必须丢弃旧样本重设基线**（联网单次约 100 秒 vs 千问约 9 秒） |
| 元宝 / 百度AI / 文心 / 抖音AI | 无公开 API，只能网页/App 人工采样回灌 |

**边缘探针局限**：探针 IP ≠ 真实爬虫 IP，按 IP/rDNS 验证的 WAF 可能拦探针放真爬虫——探针结果标注"可能"而非"确认"。
