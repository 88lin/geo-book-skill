## 三、逐版规格核对

**知乎问答版**

- [ ] 标题 = 用户原话问句
- [ ] 第一句 40–60 字结论前置
- [ ] 正文 = 分场景建议 + 对比表
- [ ] 负面语义主动占位（中立、给判断标准："什么情况下值得、什么情况下是坑"）

**公众号长文版**

- [ ] ≥3000 字完整长文，有叙事、有案例细节
- [ ] 结论前置改成"开头摘要"段
- [ ] 文末挂权威信源链接（教育类必须挂教育部、阳光高考、研招网这类官方源）
- [ ] 前置确认：**有没有公众号矩阵**——没有就先补基建（注册 + 内容），不是换渠道硬凑。元宝这条路没有公众号就是断的

**头条短文版**

- [ ] 800–1500 字，单点切入，一篇只讲一个问题
- [ ] 保留结论前置 + 一张对比表
- [ ] 砍掉长叙事
- [ ] （可选）延伸口播短视频，文字稿同步头条号

**官网事实页**

- [ ] 产品参数 / 定价（带日期）/ FAQ
- [ ] 全平台口径一致
- [ ] 定位是**事实源**不是引用源——目标是 AI 描述你时口径正确，不是指望官网本身带来引用

## 四、改写检查（发布前必过）

- [ ] 三版之间**没有连续相同的段落**（复制粘贴检查）
- [ ] 数据、结论、口径三版完全一致
- [ ] 每版都符合各自的字数与结构规格（**不要拿长文的结构指标去卡头条短文**）
- [ ] 无同题重复 URL / 近重复正文（有则合并或 canonical 指向唯一版本）

## 五、边界

- 三个版本是书内规范起点不是上限——有视频能力加抖音版；海外业务本包未覆盖。
- "哪些平台被引"的结论是 2026-08-05 快照（知乎降为辅助、主要对文心有效），改造前用最新的渠道分工表（[templates/channel-matrix.md](channel-matrix.md)）。
- 低质软文铺量是负资产，"先到先得"不等于灌水。
