## 一、四条硬指标（准入门槛，任何一条 fail 直接修）

|---|---|---|---|---|---|

## 三、结构硬指标（量化）

⚠️ **先判适用范围再填本节。** 下列阈值来自海外长文型页面的量化研究，**只适用于官网页与博客/支柱长文**。平台短文按各自规范判，把长文阈值套上去会把合格稿判成全 fail：

| 稿件类型 | 本节怎么用 |
|---|---|
| 官网页 / 博客长文 / 支柱页 | 全表适用 |
| 头条短文版（800–1500 字） | **整节标 N/A**，按 one-fish 规范判：单点切入、结论前置、保留一张对比表 |
| 知乎问答版 | 只看"对题性"与"可引段落数"两项，其余标 N/A |
| 公众号长文版（≥3000 字） | 全表适用，但"列表密度"可放宽（长文叙事成分高） |

| 指标 | 目标值 | 实测 | pass/fail/N-A |
|---|---|---|---|
| H1 | 唯一 | | |
| H2 数量 | ≥6（目标 8–10 节） | | |
| 段落数 | ≥25 | | |
| 列表密度 li/(li+p) | ≥0.35 | | |
| 字数 | 首页 500 / 博文 1500 / 支柱页 2000-5000 / 产品页 300 / FAQ 500（**地板不是目标**） | | |
| 可引段落数 | ≥1（判据：词量 ≥60 且含数字/定义句/操作步骤中至少一种） | | |
| 对题性 | 标题 / H1 / H2 含目标 query 的实际用词 | | |

整页 ≥3 节、≥300 词却零可引段，是最严重的结构性失败（NO_QUOTABLE_PASSAGE）——修法是让每个段落开头直接回答小节标题的问题。对题性是最强预测因子（r=0.432，高于语义相似度 0.356 与内容质量 0.292），**这一项对所有稿件类型都适用**。

## 四、段落级评分（同主题多段之间择优排序用，非准入门槛）

页面分 = 最优 5 段均值，满分 100。**这个 100 分与第六节的 E-E-A-T 100 分是两套独立口径，不相加、不平均**——段落分量的是"内容好不好用"（可引用性），E-E-A-T 量的是"来源可不可信"，两者是独立判断维度。

| 维度 | 满分 | 本稿得分 | 关键信号 |
|---|---|---|---|
| 答案块质量 | 30 | | 定义句式（"X 是…"）、答案出现在前 60 词、问句式标题、短句、有出处的断言 |
| 自包含 | 25 | | 段落 134–167 词最优；代词密度 <2%；专名 ≥3 个 |
| 结构可读 | 20 | | 平均句长 10–20 词；列表式过渡词；编号步骤；分段 |
| 统计密度 | 15 | | 百分比/金额/带单位数字/年份/具名来源 |
| 独特性 | 10 | | 原创研究表述、真实案例引用、具体产品/工具提及 |
| **合计** | **100** | | |

**统计判定排除清单**：无具名来源的"研究表明"、无具名专家的"专家认为"**不算**统计。

**自包含五问**（逐段自检）：① 不以 But/However/这/它/上述等依赖前文的词开头？② 显式命名主题？③ 只读本段可懂？④ 至少 1 个具体事实？⑤ 50–200 词？

## 五、页面类型专项

按稿件类型只勾选适用的一组：

**对比页四规则**

- [ ] 同口径 6–10 个维度（不给自己加独有维度）
- [ ] **写了自己的局限**（只夸自己的对比页可信度极低）
- [ ] 结论挂来源
- [ ] 结尾给"如果你是 X 且看重 Y → 选 Z"决策树

**榜单页**

- [ ] 评选方法（维度、权重、数据来源、利益披露）写在榜单正文**之前**——没有方法论的榜单在 AI 眼里就是软文

**定义页**

- [ ] H1 直接给结论，首段 60 字内完成定义
- [ ] JSON-LD description 与首屏定义**逐字一致**

**FAQ 页**

- [ ] 问句标题对齐引擎查询扇出的真实子问题（不凭空编造）
- [ ] 答案第一句就是结论
- [ ] 注意：纯 Q&A 格式本身实测 −5.7%，FAQ 的价值在"问法召回"不在格式

## 六、E-E-A-T 代理信号

与第四节的段落分**分开算，不相加**：段落分量"内容好不好用"，本节量"来源可不可信"。AI 引擎不直接计算 E-E-A-T，而在检索/采信/模型先验三环节用下列代理信号。

| 维度 | 0–25 | 判据 |
|---|---|---|
| 经验（Experience） | | 亲历细节、原始数据、截图、"我们实测过" |
| 专业（Expertise） | | 具名作者 + 可核实简介 + sameAs |
| 权威（Authoritativeness） | | 高可信来源引用、品牌提及、知识图谱存在度 |
| 可信（Trustworthiness） | | 断言可核实、信息及时、站内自洽 |

Google 原话：**可信最重要，其余三者都为它服务**。

**伪造 E-E-A-T 四反模式（出现即整改，不是扣分）**：编造作者、凭空统计、批量 AI 内容、堆砌引文。

## 七、收束检查

- [ ] 给结论（可被转述的判断，不是产品夸赞）
- [ ] 给数字（带日期、可核验）
- [ ] 给适用边界（**写了"不适合谁"**——适用边界 3 条 / 不适合 2 条是标准件，显著提升可信度与被引用率）
- [ ] 同题无重复 URL、无近重复正文（有则合并或 canonical 指向唯一版本）
- [ ] 非孤儿页（同主题聚合互链）
