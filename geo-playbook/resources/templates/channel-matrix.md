填表参考（按引擎生态）：

- 豆包 → 头条号 + 抖音号矩阵（字节系霸榜）
- 元宝 → 公众号长文（没有公众号矩阵这条路就是断的，属刚性约束不是优化项）
- 文心 → 百家号 + 百度百科 + 百度知道（门槛最低，可铺量）
- DeepSeek / 千问 → 门户（搜狐/网易/新浪）+ 百度百科 + 官网事实页 + 权威媒体 + 飞书公开文档
- 千问额外：优化夸克搜索收录 ≈ 优化千问（sm.cn 占 19.2%）

按题型修正：

| 题型 | 渠道修正 |

## 外部信源计划（性价比优先级）

按信源四层优先级排，别一上来就砸官网（官网仅占全库引用 1.37%）：

| 层 | 目标信源 | 动作 | 优先级 |
|---|---|---|---|
| ① 跨平台通吃层（覆盖多个平台端的域名，一次投入全平台受益） | | | 最高 |
| ② 平台生态层（百家号 / 公众号 / 头条号） | | | 高 |
| ③ 专业内容层（CSDN / 博客园 / 行业垂媒） | | | 中 |
| ④ 官网事实源（不追求引用量，追求口径正确） | | | 收尾 |

商业推荐/榜单站（maigoo、smzdm、chinapp、cnpp 等 28 家）吃掉 9.1% 引用且位置最靠前，是国内最常被忽略的一块——列进第 ① 层评估。
