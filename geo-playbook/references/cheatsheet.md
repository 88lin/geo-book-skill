# 决策规则速查 — 从 SEO 到 GEO：AI 时代的搜索优化实战手册

## 一、能力规则一句话

| 能力 | 一句话规则 |
|---|---|
| GEO 渠道决策树与六引擎信源地图 | 先按目标用户动线定主攻引擎，再按引擎生态与问题类型定渠道与形态。 |
| 三类黄金问题识别与内容公式 | 按提问动机把 query 分诊为症状/对比/信任三类，套对应内容公式产出稿件骨架。 |
| 可引用内容四条硬指标 | 结论前置 40-60 字、对比表 5+ 维度、价格带日期、数字可验证——给结论给数字给适用边界。 |
| GEO query 研究与分级 | 从真实语料捞 query，按决策阶段×引用性×竞争度三维分级，先做 easy_win。 |
| 一鱼多吃多平台改造 | 同一份研究改造成知乎问答版/公众号长文版/头条短文版+官网事实页，改写而非复制。 |
| GEO 监测与迭代 | 监测目标 query 下 AI 引没引你，按被引/竞品被引/无引用三分支迭代，两周一个周期。 |
| 引用行为实测规程（先测后投与风控红线） | 独立新对话逐字实测引用率（几/12 二值口径），先测引用再决定投入，自动化必须限速。 |
| 负面语义占位 | 对"智商税/靠谱吗"类 query 抢阅卷权：替用户算账、分人群给结论、借第三方形态呈现。 |
| LSO 本地商户五步执行 | 本地排名三要素诊断 + NAP/评价运营/本地内容三件套，五步执行赢过商圈大多数同行。 |
| VSO 视频搜索优化与双吃路径 | 视频是给人看的，搜索引擎只能读字——标题贴原句、关键词进字幕、合集、评论区置顶，视频主攻对比题、图文兜底症状题。 |
| AEO 答案位三板斧与占位五步 | 结构化问答、FAQPage schema、Speakable 三板斧——把内容加工成机器好嚼的形状，占住位置零。 |
| 品牌数据基建三层 | 结构化数据、API 化内容、官方事实页三层基建，官方口径缺位的地方自然有别人的嘴替你填上。 |
| AI 爬虫可访问性与 llms.txt（补充自 GEO Wiki） | AI 爬虫按用途三类决策（训练/检索/用户触发），检索类必须放行；llms.txt 低成本预部署但不指望带来引用。 |

## 二、关键数字速查（**引用时必须带口径，不得转写成精确百分比**）

### 六引擎画像（原书，2026-08-05 单日单账号 12 题 × 6 引擎，方向性）

| 引擎 | 单次引用 | 主信源 | 打法要点 |
|---|---|---|---|
| 文心一言 | 12/12 | 百度系（百科/百家号/知道） | 门槛最低，铺量有效；每题 21–33 条引用 |
| 元宝 | 10/12 | 公众号（采样约 80% 含公众号） | 公众号是入场券，属刚性约束 |
| 千问 | 10/12 | 53 个去重域名，引用面最广 | 优化夸克/神马收录 ≈ 优化千问 |
| 豆包 | 9/12 | 字节系（抖音视频 9 题、头条 7 题） | 症状型口语题多次采样 0/4 纯模型作答，须图文兜底 |
| DeepSeek | 9/12（单次） | 媒体 + 投诉/政务 + 官网，"杂而正" | 多次采样 32/32 全联网——**单测会系统性低估它** |
| Kimi | 3/12 | — | 基本不联网，官网事实页顺手覆盖，不专门投入 |

### 大样本（GeoLook CN-GEO v2.0.1，2026-07-14，187,818 条去重引用实算）

- 品牌官网类信源占全库引用 **1.37%** —— 官网是**事实源**不是引用源
- 28 个商业推荐/榜单站吃掉 **9.1%** 引用且位置最靠前（国内性价比最高、最常被忽略的一块）
- qq / toutiao / baidu / iesdouyin 四家内容平台占 **16.4%**
- 生态集中度（各平台 Top8）：百度 AI 66.2%（baidu.com 自家占 37.7%）、文心 66.8%（自家 29.0%）、Kimi 47.9%、DeepSeek **21.8% 最分散最中立**、千问吃夸克/神马 19.2%、元宝 qq.com 20.5%
- 抖音 AI 只引 iesdouyin.com 一个域名，外部内容进不去
- **Web ≠ App**：千问两端信源重合仅 24.5%；豆包 App 端 iesdouyin 占 28.1% vs web 端 12.0%
- 引用位置（average_quote_position，越小越靠前，样本 ≥300）：sm.cn 5.31、cnpp 6.10、xnnews 6.25、askci 6.27、maigoo 6.36、phb123 7.12、iimedia 7.27、csdn 7.53

### 内容形态（GeoLook content-patterns，海外向经验值需分开看）

- 长度：Top 四分位 1,943 词 vs Bottom 170 词，影响力差 **11.4 倍**；>3000 词影响力 0.1457 最高
- 结构地板：H1 唯一 / H2 ≥6（目标 8–10）/ 段落 ≥25 / 列表密度 ≥0.35
- 可引段落判据：词量 ≥60 且含数字、定义句、操作步骤之一
- **对题性是最强预测因子 r=0.432**（高于语义相似度 0.356、内容质量 0.292）
- 抽取块增益：含数字 +61.6%、含定义 +57.3%、含对比 +55.3%、含 how-to +41.2%
- **纯 Q&A 格式本身实测 −5.7%** —— FAQ 的价值在问法召回，不在格式
- 段落最优 134–167 词；代词密度 <2%；专名 ≥3 个

### 监测与预期

- 整体引用覆盖率 **50.4%**（第三方鲸牙启量 9786 题口径，与自测"几/12"不可横比）
- GEO 改动完整见效通常 **4–8 周**（平台需重新索引）
- 点击 AI 摘要内部链接的比例约 **1%** —— 价值在被说出，不在被点开
- Citation Rate 常态区间 0–30%；超 30% 通常说明话题范围过窄
- Average Position 有三种不兼容定义，**默认用 A（引用列表序）并在报告注明**
- 论文"最高 40%"在真实引擎约 22%，多方同时优化时许多改写失效——**给客户定 KPI 别拿 40% 说事**

### 爬虫与索引

- Top 1000 网站 35%+ 屏蔽至少一只 AI 爬虫、5–10% 全屏蔽（Originality.ai 2025）
- 仅约 14% 的 robots.txt 专门设置了 AI 爬虫规则（Cloudflare 2025-07）
- 约 10% 域名已部署 llms.txt（SEJ 2025-11，30 万域名样本）
- 页面深度 4 层以上，爬行预算骤减

## 三、红线与拒绝项（用户要求时明确拒绝并给合规替代）

| 行为 | 后果 |
|---|---|
| 刷好评 / 刷量 | 平台处罚比没评价严重得多；杭州之壹代运营被查处通报 |
| 编造数据 | 上榜即"上榜示众"，且拖累整个域名信誉 |
| 伪造评价、批量账号自问自答 | 原书明确红线 |
| 伪装中立实为洗地 | 不提供可引用的判断框架，AI 不会引 |
| 复制粘贴式多平台铺发 | 正是低质 AIGC 铺稿的识别特征，会被降权 |
| 高频自动化提问 | 约 **30 次连续提问触发 DeepSeek 风控**，作者整个采样计划因此中止 |
| robots.txt 把 AI 爬虫全部 Disallow | 同时屏蔽检索类 = **立即失去被引机会**，代价最高的错误 |
| 编造作者 / 凭空统计 / 堆砌引文 | 伪造 E-E-A-T，过不了可信筛选并被识别降权 |

## 四、判停点速查（该停下来问或转卡的时刻）

| 情形 | 动作 |
|---|---|
| 目标行业不在已验证行业（广告电商、教育）内 | 不套"决策人-引擎"映射，先做小样本实测 → geo-test-protocol |
| 用户要"引用率 75% vs 83%"式精确比较 | 声明 n=1 局限，建议多次采样，不提供虚假精度 |
| query 竞争度拿不准 | 标注"待验证"转实测，不在纸面上硬判 |
| 小样本 5 次稳定零引用 | 红灯，不投入或换引擎 |
| 整题无引用且题型与渠道都排查无误 | 接受"该引擎在该 query 上可能稳定不联网"，复测确认后再决定放弃 |
| 缺目标 query 原话 / 决策人画像 / 品牌立场 / 语料来源 / robots.txt 现状 | 停下来问，**不猜值、不代填产品参数与价格** |
| 元宝路线但用户没有公众号矩阵 | 先补基建（注册 + 内容），不换渠道硬凑 |
| 底稿没有明确核心事实 | 先停下确认，不硬改 |
| 触发平台风控 | 立即停止自动化提问保账号，改限速或转现成工具 |

## 五、口径纪律（一句话版）

- 所有引擎数字是 **2026-08-05 单日快照**或第三方数据集口径，按方向性使用，重要决策前复测
- 引用 ≠ 提及 ≠ 链接；被检索到 ≠ 被采信 ≠ 被署名
- API ≠ 网页端，Web ≠ App，中文查询结果不得与英文查询结果相加
- 不同第三方口径不横比；区分相近指标时**公式比名称可靠**
- 国内与海外是两套市场两套打法，结果不可互推（同一查询仅 11% 域名被 ChatGPT 与 Google AIO 同时引用）
- GEO 提高的是被引用概率，不是保证；不承诺 ROI
