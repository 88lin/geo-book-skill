# GEO query 研究与分级

> 能力单元 geo-query-research ｜ 来源：《从 SEO 到 GEO》第 10 章（第一步：Query 研究）、第 1 章、第 9 章

## R — 原文

> "从真实语料里捞 query，不要自己编。我们的语料来源是知乎原题、百度下拉联想、贴吧和百度知道的用户原话，按真实口吻保留。"（ch10）
>
> "按"决策阶段 × 引用性 × 竞争度"给 query 分级。我们的做法是：选型/解决问题类 + 容易被引用 + 竞争空白 = 先做（easy_win）；纯定义类……跳过。"（ch10）

出处：ch10《方法论与工具》第一步；选词原则 ch1；价格锚点信号 ch9。候选来源：f22, p68, p69, p70, p09, p10, p66。

## I — 解释

GEO 的起点不是关键词工具，而是研究"人怎么跟 AI 说话"。AI 对话框里的问题与知乎/贴吧/百度知道的提问高度同构——全是口语化的"症状"和"焦虑"。流程三步：

1. **捞词**：从真实语料捞，按真实口吻保留，不自己编。来源：知乎原题、百度下拉联想、贴吧、百度知道、评论区、客服记录。
2. **三维分级**：逐条标注决策阶段（选型/解决问题/纯定义）、引用性（是否容易被 AI 引用）、竞争度（现有答案供给）。交叉定级：easy_win = 选型/解决问题 × 易被引用 × 竞争空白（优先做）；target = 常规投入；skip = 纯定义类（AI 直接用训练数据回答，引用率天然低）。
3. **排序纪律**：先 easy_win（症状型 how-to、工具对比、信任评估），再 target（选型、成本类价格页），明确放弃纯定义类。产能口径：一个月做透 10 条 easy_win 胜过铺 100 条平庸稿。两行业样本中 easy_win 占比都在六成上下——GEO 仍是大片空地。

辅助信号：带具体价格锚点的 query（"价格带+具体数字+差在哪"三段式）引用潜力普遍 high；信任焦虑类（"割韭菜吗""靠谱吗"）有大量真实提问但优质中立答案稀缺，是蓝海；优化用户的问法，不是你的叫法。

## A1 — 书中案例

- **两行业 prompt 库分布（作者亲历，ch9 图 1）**：广告电商 34 条 + 教育 40 条候选 prompt，easy_win 占比都在六成上下；"松鼠 AI 自习室加盟是不是骗局"等新兴负面 query 标注 competition: none。注意：占比来自这两个行业的样本，不是全行业规律。
- **对比题真空（书中转述，ch8）**："晓多跟乐言比店小蜜"在百度知道还挂着 2019 年的老帖子无人更新——大量对比类问题全网没有一篇像样的新答案。

## A2 — 未来触发

- 用户要启动 GEO/内容项目，问"该先写哪些题目 / 帮我列选题清单"。
- 用户拿着关键词表问"GEO 该按什么标准挑题"。
- 用户问"哪些问题不值得做"（纯定义类、无引用题）。
- 语言信号：选题、query 清单、easy_win、优先做哪些题、竞争空白、蓝海 / topic list, keyword research, which questions to target。
- 与相邻能力区分：本卡产出"分级 query 清单"就停；清单上每条怎么写归 golden-question-formulas + citable-content-spec；该投入哪个引擎归 geo-channel-map；值不值得投入的实测筛子归 geo-test-protocol（本卡 easy_win 是纸面判定，先测后投是实测确认）。

## E — 执行步骤

输入契约：行业/产品领域；1–2 个真实语料来源（客户提供或指定）；产能约束（每月可产量）。语料来源缺失时列出建议来源请用户确认，不用编造 query 凑数。

1. **捞词**：从指定语料逐条抄录用户原话（保留口语、错别字级别的真实度）；辅以搜索下拉联想、评论区、客服记录。
2. **去噪**：剔除品牌内部叫法（改写成用户问法）；同问合并。
3. **三维标注**：每条标 [决策阶段, 引用性, 竞争度]，缺证据的字段标"待验证"而不是猜。
4. **定级**：三维交叉→easy_win / target / skip；信任焦虑类单独标"蓝海"；带价格锚点的标 high 潜力。
5. **排序**：easy_win（按竞争度升序）→ 蓝海负面 → target；skip 归档不投入。
6. **输出**：query 清单表（列：query 原话 / 决策阶段 / 引用性 / 竞争度 / 分级 / 建议题型 / 建议引擎）。完成标准：每条都有三维标注与分级，无编造条目。

判停点：某条 easy_win 的竞争度拿不准时，标注后转 geo-test-protocol 做小样本实测，不在纸面上硬判。

## B — 边界

- easy_win 六成占比来自广告电商（34 条）与教育（40 条）两行业样本，其他行业不可直接外推。
- 三维分级依赖人工标注经验，书中给的是判定方向而非评分公式——两个标注人应先对齐口径。
- 分级是纸面判定，"看起来干净"的卡位仍可能被引擎稳定不联网（元宝 0/5 警示），投入前必须实测（geo-test-protocol）。
- 纯定义类 skip 的依据是"AI 直接用训练数据回答"，这是 2026-08-05 快照下的观察，随引擎迭代漂移。
