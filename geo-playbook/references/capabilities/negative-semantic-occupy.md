# 负面语义占位

> 能力单元 negative-semantic-occupy ｜ 来源：《从 SEO 到 GEO》第 9 章（负面语义占位）、第 8 章（信任型）

## R — 原文

> ""是不是智商税"像贴在店门口的差评大字报，你撕不掉，但可以在旁边贴一张更详细的"本店价格构成说明"——路人两张都看，但只有一张是你写的。谁提供判断框架，谁就定义什么叫智商税。"（ch9）
>
> "正确姿势是替用户把账算清，然后分人群给结论——什么孩子值得买、什么情况它就是吃灰的平板，一条条说透。"（ch9）

出处：ch9《负面语义占位》；信任型引用规则 ch8。候选来源：f18, p59, p60, p54, p48。

## I — 解释

"智商税""割韭菜""靠谱吗""骗局"类 query 是教育等行业的提问主战场（教育消费试错成本不可回收，家长开口第一句永远是排雷）。品牌的本能错误是公关式否认（"我们不是"）——它不提供可供引用的判断框架，AI 不会引；你不占位，答案就被吐槽帖定义。

正确姿势四条：

1. **替用户算账**：把价格构成、适用条件、风险点一条条说清。
2. **分人群给明确结论**：什么情况值得买、什么情况它就是吃灰的平板——"分人群明确结论的内容被引用"（书内 prompt 库标注的提及机制）。
3. **抢阅卷权的心态**：负面占位不是抹黑自己，是提供判断标准；差评大字报撕不掉，但旁边可以贴一张自己写的说明。
4. **借第三方形态呈现差异点**：资质公示、可验证学员案例、退费条款，最好出现在媒体、行业站、问答平台——信任题的引用天平压向投诉平台/监管/权威媒体，品牌自辩无效。

**烈度分级决定投入方式**：存量老负面（"学习机是不是智商税"在知乎至少 5 个问题在抢，竞争 medium）→ 拼质量打阵地战；新兴负面（"松鼠 AI 自习室加盟是不是骗局"竞争几乎为零）→ 窗口期短，先到先得拼速度。

## A1 — 书中案例

- **"短视频带货训练营是真的吗"六家实测（作者亲历，ch8）**：DeepSeek 引黑猫投诉和 315 平台，文心的参考资料几乎是一份监管点名册（达州/湖南/襄阳/海口/山西省市监局），千问引新华社/央广网/北京市监局，元宝直接指路 12315。六家结论趋同结构：真有正规训练营，但"月入过万包教包会"的大多是割韭菜（低价引流→制造焦虑→连环收费），并给新手指路免费教程——不一棍子打死、不和稀泥、给识别标准。

## A2 — 未来触发

- 品牌方发现 AI 回答自家产品时引用了吐槽帖/负面内容，问"怎么办"。
- 品牌面对"智商税/骗局/靠谱吗"类 query 要不要回应、怎么回应。
- 内容团队排负面 query 清单的优先级。
- 语言信号：智商税、割韭菜、靠谱吗、辟谣、负面口碑、差评占位、AI 说我不好 / scam, is it legit, negative sentiment, rebuttal。
- 与相邻能力区分：本卡是品牌侧的占位策略与烈度分级；单篇信任型内容的通用写法归 golden-question-formulas（其"信任型公式"是本卡第 4 条的取材基础）；稿件硬指标归 citable-content-spec。

## E — 执行步骤

输入契约：负面 query 及其烈度信息（搜索/问答平台上现有竞争情况）；品牌可公开的事实（资质、价格构成、退费条款、可验证案例）。事实清单缺失时先向用户索取，不代编。

1. **盘点与分诊**：列出涉及品牌的负面句式 query；逐条判烈度——存量老负面（多题竞争）→ 阵地战；新兴负面（竞争≈0）→ 抢速度先发。
2. **定框架**：禁用公关式否认；写"分人群判断框架"——给可操作的识别标准（"什么情况下值得/什么情况下是坑"），替用户把账算清（价格构成、适用条件、退出成本）。
3. **借第三方形态**：差异点整理成可被第三方引用的材料（资质公示页、可验证学员案例、退费条款），推动其出现在媒体/行业站/问答平台；测评方则做带投诉数据与识别清单的评估文章。
4. **落渠道**：按 geo-channel-map 题型修正——信任评估类 → 挂投诉/政务数据的内容 + 百家号；B 端私域题 → 公众号 + 百家号。
5. **输出**：占位稿骨架（标题=负面 query 原话；分人群结论节；算账节；识别标准节）+ 烈度判定与投入节奏。完成标准：稿件不含自夸式否认语句，含至少一个分人群明确结论与可核验依据。

## B — 边界

- 红线：不在"智商税"类问题下伪装中立实为洗地、不编造数据、不伪造用户评价（作者"四不"之一）；造假内容存活期越来越短，真实数据型内容才是长期资产。
- 老负面是阵地战，别指望一篇稿子翻盘；新负面窗口期短，但"先到先得"不等于灌水——低质 AIGC 铺稿正被降权。
- 烈度数字（"至少 5 个问题在抢"）来自书内 prompt 库观察（2026-08），使用前自行核实当前竞争。
- 信任题引用源级别（投诉/监管/央媒）是实测观察，若引擎行为变化需复测（geo-test-protocol）。
