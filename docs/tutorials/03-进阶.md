# 教程 03 · 进阶：把 GEO 做成闭环

## 一、先测后投：别在纸面上拍板

技能包最值钱的纪律之一是**"引用率先行测试"**——任何"看起来竞争空白"的卡位，投入内容前先实测引擎在该题上引不引用。真实教训：元宝对"用 DeepSeek 辅导孩子作业靠谱吗"5 次独立采样 0/5 引用，而同批题它整体引用率 81.7%——0/5 不是偶发，是引擎对价值观类开放题的策略性选择。

**你说**：
> "AI 填志愿靠谱吗"这个题在元宝上看起来没人做内容，值不值得投入？帮我设计测试。

**agent 会给**：1 题 × 目标引擎 × 5 次独立采样的方案（每题全新独立对话、逐字提问不改写、分钟级人工间隔），二值口径记录"是否带出可提取引用"，判读规则（0/5 稳定零引用=红灯不投入；有引用→再核对引用源级别你够不够得着）。

**三条实测纪律**（违反会被 agent 纠正）：
1. 每题开全新独立对话——上一题的上下文会"串味"。
2. 单次 n=1 只作方向性信号，禁止"引用率 75%"式精确报告。
3. 自动化必须限速：约 30 次连续提问会触发 DeepSeek 风控（作者实测踩坑）。用户要求"1 小时连问 500 次"会被拒绝并给限速方案。

## 二、判停点哲学：技能什么时候会说"先别做"

这套技能的边界段（B 段）不是免责声明，是防浪费的闸门。两类典型判停：

- **行业外推判停**：原书实测只覆盖广告电商和教育。"决策人-引擎"映射（教育→元宝/文心，3C→知乎优先）因行业而异——你的行业不在其中时，agent 会先给实测方案而不是直接套渠道表。这正是"知乎修正"的教训：作者自己基于搜索语料推断"知乎是主阵地"，实测发现知乎几乎只在文心引用里出现——**传统搜索里的权重 ≠ AI 引用里的权重**。
- **引用率筛子**：纸面分级（easy_win）只是第一道筛，"看起来没人做"的题可能是"引擎根本不联网答这类题"。两道筛都过再投入产能。

## 三、把账算给老板：归因三段

"AI 经常提到我们"不等于"带来了生意"。归因三段链路（源自 GeoLook）让这笔账可测：

```
① 采样测"答案里有没有你" → ② referrer/UTM 测 AI 带来多少会话 → ③ 转化事件测这些会话值多少钱
```

落地动作：在各引擎 referrer 域名清单（chatgpt.com、perplexity.ai 等，先在自家日志里核对）上打 UTM/来源分组；接受"App 内打开常不带 referrer，②测的是下界"；三段都测了，归因才脱离"观察相关"。同时记住口径三坑：**提及 ≠ 引用 ≠ 链接**，混计会高估。

## 四、配合 GeoLook：方法论 + 自动化流水线

`geo-playbook`（本技能）和 [GeoLook](https://github.com/aigclink/geolook)（独立 Skill，MIT）是互补关系：

| | geo-playbook | GeoLook |
|---|---|---|
| 形态 | 13 张方法论能力卡 | 自托管 Python 流水线（20+ 脚本 + Web 界面） |
| 强项 | 为什么、怎么选、怎么写（决策树/公式/体检表） | 跑起来：六维站点体检、17 引擎采样、工单、自动验收、客户交付包 |
| 典型问题 | "内容该发哪里？" | "给我官网做一次 GEO 诊断出报告" |
| 依赖 | 无（纯指令） | Python 3.9+、requests/bs4/lxml、各家 API Key |

两者可同时安装。典型组合拳：用 GeoLook 跑一轮 `new --url 你的官网` 拿到诊断报告和"AI 实际引用的信源 Top"→ 把结果带回 geo-playbook 问"这个诊断结果该怎么排渠道优先级" → 按一鱼多吃改造 → 下期用 GeoLook 复测验证。

## 五、数据保鲜：这套技能会过期吗

- 引擎信源数字的快照是 2026-08-05（原书实测），GeoLook 数据集是 2026-07-14——作者自认"打法保质期两三年"，具体数字漂移更快。
- 技能把"定期复核"内置成了纪律：重要决策前，按 geo-test-protocol 用最新行为复测；渠道结论以"方向性"使用。
- 复合策略：把有限精力投在跨期稳定的东西上——**结论前置、对比表、带日期的可验证事实、真实数据**（"唯一不变的策略，是成为值得被引用的答案"）。

## 六、常见误区速查

| 误区 | 正解 |
|---|---|
| 把官网做到 90 分等 AI 来引 | 官网是事实源不是引用源（仅占 1.37%）；外部阵地是引用大头 |
| 一套内容全平台复制 | 一鱼多吃=改写；复制粘贴是降权特征 |
| 让 AI 夸我 | 对比题 AI 只给分流式平衡答案，目标是进名单+分流理由有利 |
| 在 Kimi 上重投内容 | 引用率 3/12，官网事实页顺手覆盖即可 |
| 监测天天盯 | 两周一个周期，天天盯只是焦虑 |
| 信"十大 GEO 服务商排行榜" | 基本是厂商自费软文 |
| 屏蔽所有 AI 爬虫保安全 | 屏蔽检索类=立即失去被引；按三类分别决策 |
