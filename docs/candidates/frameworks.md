  type: procedure

  source_quote: |

  summary: |

    ①选题——从 prompt 研究筛真实用户查询（不自己编），覆盖两行业×五种提问动机：对比题（购买决策）、症状题（求医问药）、方法题（要流程）、信任题（要不要信）、选型/私域题（钱袋子）；这五动机即商家要争夺的全部入口。

    ⑦记录平台测试成本（登录态、匿名额度）；明示局限（单账号、单日、行业覆盖）。
    ⑧结论按"方向性+定期复核"使用，不产出"测完管三年的报告"。
