> 执行方式：干净 sub-agent（无蒸馏上下文），只装对应能力卡；输出写 /tmp/geo-eval/<skill>-{normal,boundary}.md。
> 首版无 old_skill 变体，只跑 new_skill；未做三变体对比在此声明。
