# 从 SEO 到 GEO — 术语词典（GLOSSARY）

> 口径以原书作者用法为准（非字典定义）。来源：candidates/glossary.md（30 条，逐条回原文核验）。

| # | 术语 | 作者的用法 | 首次定义位置 |
|---|---|---|---|
| g01 | SEO | 让网页在搜索结果列表里排得更靠前；核心资产思维"排名是租的，内容是买的"；GEO 的地基基本功 | 前言、第 1 章 |
| g02 | 内容质量三问 | 真回答问题？有增量信息（information gain）？背后有没有懂行可信的人（E-E-A-T）？ | 第 1 章 |
| g03 | LSO | 让"附近的人"在地图和本地结果里找到你；本质是"进入三公里生活圈的认知"；三要素=相关性/距离/知名度 | 前言、第 2 章 |
| g04 | NAP 一致性 | 店名/地址/电话在所有平台一字不差；不一致=平台降低信任的隐形扣分 | 第 2 章 |
| g05 | VSO | 让内容在视频搜索和语音问答中被找到、被念出来；GEO 的前传（豆包引视频读的是文字层） | 前言、第 3 章 |
| g06 | 双引擎 | 推荐=逛街被搭讪（让人停下来），搜索=主动问导购（让机器听懂）；成交大头来自搜索 | 第 3 章 |
| g07 | 答案胶囊 / 可引用件 | 可被机器直接取用的内容单元；单位是段/句不是篇；一句话吃搜索、AI 引用、语音朗读三个场景 | 第 3、5 章 |
| g08 | AEO | 让机器直接引用你作为"那个答案"；三板斧=结构化问答/FAQPage/Speakable；"AEO 教机器找答案，GEO 教机器信答案" | 前言、第 4 章 |
| g09 | 位置零 | 精选摘要答案位：赢家通吃+信任转移；值得抢但不是流量全部（Ahrefs：8.6% vs 19.6%） | 第 4 章 |
| g10 | 结构化数据 / Schema | 给机器递"填好的图书卡"，降低机器理解成本；从 SEO 功课升格为数据基建第一层 | 第 1、4、11 章 |
| g11 | 结论前置（40–60 字） | 开头 40-60 字直接回答问题再展开；"净菜规格"而非写作技巧 | 第 4、10 章 |
| g12 | GEO | 优化内容的结构、可信度和分发位置，让 AI 引擎引用你、推荐你、替你说好话；优化的是"被采纳的资格" | 前言、第 5 章 |
| g13 | 零点击的胜利 | 用户看完 AI 答案直接决策，官网 UV 零变化但这单成了；盯流量报表做 GEO="用体温计量体重" | 第 4、5 章 |
| g14 | 信源网络 | AI 生成答案依赖训练语料+联网检索，每家引擎"抓哪信哪"偏好完全不同——六个阅读习惯不同的导购员 | 第 5 章 |
| g15 | 有机引用窗口期 | 截至 2026 年初六家均无 AI 广告产品，所有"被 AI 推荐"都是有机结果；内容能力第一次压过预算能力 | 第 5、11 章 |
| g16 | 引用率 / 引用覆盖率 | 二值口径（这道题引没引，记"几/12"）；第三方口径 50.4%；引申用法"引用率筛子"=先测引用再投入 | 第 6、9 章 |
| g17 | n=1 / 多次采样 | 单次测试只作方向性信号；多次采样才是统计口径；所有数字按"方向性"使用 | 第 6 章 |
| g18 | 推断 vs 实测 | 渠道结论的证据分级标签；"没有实测数据背书的渠道结论，都按假设处理" | 前言、第 7 章 |
| g19 | 生态绑定定律 | 有内容生态的引擎优先引用自家生态内容；想影响它，先进它的供应链 | 第 7 章 |
| g20 | 信源地图 | 各引擎被实测验证的引用域名/渠道分布——"AI 从哪进货"的地图；七分看渠道三分看内容 | 第 7 章 |
| g21 | 知乎修正 | 作者最重要的一次认错：传统搜索里的权重 ≠ AI 引用里的权重；知乎降为辅助 | 第 7 章 |
| g22 | 三类黄金问题 | 症状型（病征求排查）/对比型（带名单要决断）/信任型（要实锤）；按提问动机分，不按关键词行业分 | 第 8 章 |
| g23 | 分流式答案 | 对比题 AI 一律给按场景分流的平衡答案；目标=挤进分流名单+分流理由有利，不是全场最佳 | 第 8 章 |
| g24 | 负面语义占位 | 对"智商税"类 query 抢阅卷权：替用户算账、分人群给结论；公关式否认无效 | 第 9 章 |
| g25 | easy_win / target / skip | query 三维分级（决策阶段×引用性×竞争度）；easy_win=竞争空白+高引用潜力，两行业各占约六成 | 第 9、10 章 |
| g26 | 一鱼多吃 | 同一事实改造成多平台形态分别喂不同引擎；分发是改写不是复制粘贴（复制是低质 AIGC 特征） | 第 5、10 章 |
| g27 | 官方事实页 | 官网上的参数/带日期价格/FAQ 页——"挂在摊位上的执照"，AI 当教材用的信源；Kimi 官网引用覆盖率 67.6% | 第 10、11 章 |
| g28 | 品牌数据基建（三层） | 结构化数据/API 化内容/官方事实页；"平台系统里没录的菜，等于不存在"（第 11 章为推演） | 第 11 章 |
| g29 | 低质 AIGC 铺稿 | 批量生成软文赌抓取概率的灰产；正被识别降权，是给域名留降权记录的负资产 | 第 5、10 章 |
| g30 | 监测迭代 | 两周一个周期追踪"引没引你、引的是谁"；三分支动作；自建必须限速（约 30 次触发风控） | 第 6、10 章 |
