# 三类黄金问题识别与内容公式

> 能力单元 golden-question-formulas ｜ 来源：《从 SEO 到 GEO》第 8 章（行业实战 I：广告电商）、第 9 章

## R — 原文

> "三大特征对应三类黄金问题：症状型、对比型、信任型。下面逐个拆。"（ch8）
>
> "对比型问题的 GEO 目标不是让 AI 说"你最好"——它不会这么说——而是挤进它的分流名单，并且让分流理由对你有利。"（ch8）

出处：ch8《行业实战 I：广告电商》。候选来源：f16, f17, p51~p54, p58, p66, p67。

## I — 解释

电商从业者等 AI 重度提问者的 query 按动机分三类，每类对应一种被 AI 引用的内容形状。先判题型，再套公式：

1. **症状型**（描述病征不带术语，"千川计划跑不动应该加价还是暂停"）：像修车师傅接诊，症状越具体越好下手。公式：症状做标题 → 排查决策树做骨架 → 每个分支给具体阈值（加多少、等多久、什么红线停）。实测中六家引擎对同类题的答案高度趋同为"诊断决策树"——谁的内容长得像决策树，谁就长在标准答案的形状上。
2. **对比型**（带着候选名单要临门一脚，"晓多跟乐言比店小蜜哪个好用"）：商业价值最高（提问者离下单一步）。实测六家一律给按场景分流的平衡答案，没有一家说"某某最好"。公式：不自卖自夸 → 按场景分流 → 给可核验选型标准（试用 7–14 天、转人工率、独立解决率）→ 让"适合你的那个人群"一眼认出自己。目标是名单席位 + 分流理由有利，不是全场最佳。
3. **信任型**（怕被骗要实锤，"短视频带货训练营是真的吗"）：AI 引用天平压向投诉平台（黑猫/315）、监管官网、权威媒体，品牌自辩无效。公式：不一棍子打死、不和稀泥、给明确识别标准；被质疑方把差异点借第三方形态呈现。

附加信号：带具体价格锚点的 query 引用潜力普遍是 high（引擎需要接得住数字的内容）；AI 工具推荐类 query 的品牌提及机制已成型，趁各家名单没锁死铺横评。

## A1 — 书中案例

- **"千川计划跑不动"六家对照（作者亲历，ch8）**：四家给出带引用的回答（DeepSeek 引抖音电商学习中心），豆包、Kimi 交白卷；六家结论趋同为"先诊断再分叉"的决策树，冷启动加价幅度惊人一致（每次 5%–15%）。同时说明：同一引擎在另一道千川题上就引用了学习中心——引不引你取决于你铺没铺路。
- **"小鹅通平替"榜单（作者亲历，ch8）**：码云数智靠内容密度五家全勤；带准确定价的内容让引擎直接报出价格细节（"课堂街 1999 元/年""码云数智 2000-4000 元/年"）。

## A2 — 未来触发

- 用户要为某道具体问题写内容，问"这篇文章该怎么写 / 用什么结构"。
- 用户拿一批 query 来问优先级和写法；或问"为什么我的对比稿没被引用"。
- SaaS/工具服务商问"帮助中心、测评、价格页怎么组织"。
- 语言信号：怎么选、哪个好、靠谱吗、是不是智商税、跑不动怎么办、对比表、测评稿、帮助中心 / vs which is better, is it a scam, how to fix, comparison post。
- 与相邻能力区分：本卡判题型给骨架；稿件是否符合"可引用规格"（40-60 字结论前置等硬指标）归 citable-content-spec；负面 query 的占位策略与烈度分级归 negative-semantic-occupy（本卡的信任型公式是它的取材基础）。

## E — 执行步骤

输入契约：目标 query（用户原话）；品牌立场（当事方 / 中立测评方 / 被质疑方）。缺 query 原话先询问。

1. **判题型**：按提问动机（不按关键词、不按行业）三分——描述病征？带候选名单？求"要不要信"的实锤？混合型拆成多道题分别处理。
2. **套公式产出稿件骨架**：
   - 症状型 → 标题=症状原句（"计划 0 消耗？按这五步排查"式，不用概念标题）→ 决策树骨架 → 分支写具体阈值。
   - 对比型 → 分流表（每场景一行：什么人选谁+可核验理由）→ 保留中立项与试用建议（7–14 天）→ 若为当事方，把自己放进名单并写实分流理由。
   - 信任型 → 识别清单（如"敢承诺包赚钱的直接排除"）+ 投诉/监管/权威媒体数据（标明来源）+ 不一棍子打死不和稀泥的结论结构。
3. **当事方附加规则**：对比题目标=进名单+分流理由有利；信任题自辩无效，差异点必须借第三方形态（资质公示、可验证案例、退费条款出现在媒体/行业站/问答平台）。
4. **工具方三件套**（SaaS/服务商，按优先级）：①帮助中心按"症状+决策树"重写（别按产品功能目录）；②对比测评自己下场写（克制、有中立项）；③价格页带日期、带版本、三笔账分开列。
5. **输出**：稿件骨架（标题+结构+每节要点+需补充的数据清单），交 citable-content-spec 做硬指标校验。

## B — 边界

- 三类公式来自广告电商与教育两行业实测，其他题型（纯方法题、纯定义题）引用率天然低，别硬套。
- 对比题写成本（竞争真空）但前提是诚实——"铺出来的东西经不起查，上榜就是上榜示众"（x28 自夸式软文不被引）。
- 症状型口语题在豆包上可能纯模型作答不联网（多次采样 0/4），内容形态需按引擎修正（见 geo-channel-map 第 3 步）。
- 实测答案是 2026-08-05 快照，"AI 一律分流式平衡答案"是当日观察，使用时以最新实测为准。
